# Sample: Inventario

Proyecto de ejemplo para AutoCode. Modela un pequeño catálogo de productos con proveedores.

Cómo probarlo:

1. Abre AutoCode.
2. En la pantalla de proyectos, crea un proyecto llamado **Inventario**.
3. Copia los archivos de `dominio/` y `pantallas/` a la carpeta raíz del proyecto creado.
4. Ve a **Agentes → Reindexar Qdrant** para que los papers se carguen en la búsqueda.
5. Ve a **Construir → Generar blueprint** para producir la app.
